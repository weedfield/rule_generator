## 目的
JS のロジックの誤りを防ぐ

## ルール
- JSL-01 条件分岐の誤り（== と === の混在、否定の取り違え、条件の抜けや重複）
- JSL-02 値がない場合の扱い（null / undefined、要素が見つからない、空配列、0 や空文字が falsy として扱われる）
- JSL-03 ループや配列の境界（最初・最後の要素の扱い、off-by-one）
- JSL-04 非同期処理の順序と失敗時の処理（Ajax の失敗時、完了前に次の処理が走る）
- JSL-05 イベントの多重登録と解除漏れ
- JSL-06 変数のスコープと再代入の誤り（ループ内でのクロージャ、意図しない上書き）
- JSL-07 型の扱い（文字列と数値の連結、parseInt の基数の省略）

## 対象外
- 規約 → js
- 多重送信 → js（JS-08）
- XSS → security
- 意図とのずれ → self-review の「意図との乖離」
