## 目的
新コーディングガイドラインに沿った CSS 設計にする

## 前提
最初に `~/.review/guidelines/coding-guideline.md` を読むこと。
ガイドラインにルールが記載されていない場合は、この観点をスキップし「ガイドライン未設定のためスキップ」と返す。

## ルール
- CSS-GL-01 BEM の書き方がガイドラインに沿っている
- CSS-GL-02 クラス名の命名がガイドラインに沿っている（既存の CSS が準拠していなくても、新規追加分にはガイドラインを適用する）
- CSS-GL-03 マージン設計がガイドラインに沿っている

指摘する際は、根拠となるガイドラインの ID（GL-xxx）を併記する。

## 対象外
- 記述上の細かな規則（小数、単位、擬似要素など） → css
