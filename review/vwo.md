## 目的
VWO（AB テスト）の実装で起きやすい不具合を防ぐ

## 前提
差分に VWO 関連の実装が含まれない場合は、この観点をスキップし「VWO 関連の変更なし」と返す。

## ルール
- VWO-01 既存の JS 関数を使う場合、同じ DOM にイベントが重複して付与されていない（一般的なイベントの多重登録・解除漏れは js-logic の JSL-05。ここでは VWO 固有の実装に限る）
- VWO-02 リダイレクト処理を行う場合、ログの送信が完了する前にリダイレクトされていない

## 対象外
- Variation ごとのログ計測用 JS → requirements
- VWO 側に記述された JS / CSS の確認 → 手動確認（manual.md）
