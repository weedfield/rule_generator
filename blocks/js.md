## JS

- JS ファイルで取得する class / id に js- の接頭辞がついているか。
- parent() や siblings(), children() など DOM の構造に左右される実装になっていないか。
- is-hidden など定数に入っているものは定数を使っているか。
- options の中身(JSDoc)を書いたか。
- jQuery オブジェクトを格納した変数名が $variable になっているか。
- グローバルを汚染していないか。
- 不要な ifExists がないか(ifExists がなく、要素がない状態でもエラーが発生しなければ不要。または、ifExists を外してもグローバル変数がなければ不要)。
- if 文の {} を省略していないか(if 文の中の処理が1行で完結しても {} を省略しない)。
- 未使用変数に _(アンダースコア)を前につけているか。
- 多重送信禁止になっているか。
