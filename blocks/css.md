## CSS

- BEM の書き方が新コーディングガイドラインに則っているか。
- クラス名の命名が新コーディングガイドラインに則っているか(既存 CSS がルールに則っていない場合でも、新規追加分は新ガイドラインを適用する)。
- 推奨環境(PC / SP)で使用できないスタイルを使っていないか。
- マージン設計が新コーディングガイドラインに則っているか。
- 要素の高さを height で固定していないか。
- モジュールごとに 1 行空けているか。
- button タグの cursor, font-family を指定しているか。
- 余白の値に小数が使われていないか。
- 子要素の margin が親要素を突き抜けていないか。
- 小数で指定している箇所は小数第1位までになっているか。
- 擬似要素は :: (コロン2つ)を使っているか。
- font-size は px で指定しているか。
- 不要な CSS 記述がないか(デフォルトのプロパティなど。block 要素に display: block; / inline 要素に display: inline; / block 要素に width: 100%; / 不要な font-size 指定 など)。
- 連続した半角英数字または全角英数字を入れた場合や、文字が長くなった場合にもスタイルが崩れないか(word-wrap: break-word; の追加など)。
- 不要な CSS が残っていないか。
